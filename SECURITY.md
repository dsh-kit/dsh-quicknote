# Security

dsh-quicknote is a build-time tool and a local-only plugin template.

- The generator writes files and copies a template; it makes no network calls.
- The template's Host half writes only to the DSH data directory; it has no telemetry.
- Report a vulnerability privately through GitHub Security Advisories on this repository
  (Security → Report a vulnerability), not in a public issue.
- Include the affected version, the DSH version, and a minimal reproduction. We aim to acknowledge within
  72 hours and to ship a patch for supported versions.
