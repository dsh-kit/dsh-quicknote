# Usage

## From the composer

Click **Quick Note** in the composer toolbar. The card opens with the current draft.

- **Save note**: stores the text and leaves the draft untouched.
- **Save and clear draft**: stores the text, then clears the composer only after the Host confirms the save.

Closing the card without saving does nothing.

## From the sidebar

**Quick Note** lists notes newest-first. Each row can be marked done/reopened or deleted. Deleting is immediate
and permanent; the list is local to your DSH home.

## From an agent

Ask the model to remember something. The plugin exposes four tools:

- `quicknote_add`
- `quicknote_list`
- `quicknote_done`
- `quicknote_delete`
