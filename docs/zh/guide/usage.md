# 使用

## 从输入框

点击工具栏的 **随手记**，卡片会带上当前草稿。

- **保存笔记**：保存文本，草稿保持不变。
- **保存并清空输入框**：Host 确认保存成功后，才清空输入框。输入框上方会出现回执，可以打开列表，或撤销并恢复草稿。

不保存直接关闭卡片，不会改动任何内容。

## 从侧栏

**随手记** 页面按时间倒序列出笔记。用 **全部 / 未完成 / 已完成** 和搜索框筛选。每一行显示时间，可以复制、
插入当前输入框、标记完成/重新打开或删除。**复制全部** 会把当前列表导出为 Markdown；`primary+alt+S` 可打开捕获卡片。删除立即生效且无法恢复；数据保存在本机 DSH home 下。

## 从 Agent

直接让模型“记一条笔记”。插件提供四个工具：

- `quicknote_add`
- `quicknote_list`
- `quicknote_done`
- `quicknote_delete`
