# Usage

## From the composer

Click **Quick Note** in the composer toolbar. The card opens with the current draft.

- **Save note**: stores the text and leaves the draft untouched.
- **Save and clear draft**: stores the text, then clears the composer only after the Host confirms the save. A receipt
  above the composer lets you reopen the note list or undo the move and restore the draft.

Closing the card without saving does nothing.

## From the sidebar

**Quick Note** lists notes newest-first. Use **All / Open / Done** and the search box to narrow the list. Each row
shows its time and can be copied, inserted into the active composer, marked done/reopened, or deleted. **Copy all**
exports the visible list as Markdown. Press `primary+alt+S` to open the capture card. Deleting is
immediate and permanent; the list is local to your DSH home.

## From an agent

Ask the model to remember something. The plugin exposes four tools:

- `quicknote_add`
- `quicknote_list`
- `quicknote_done`
- `quicknote_delete`
