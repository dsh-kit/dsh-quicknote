# dsh-quicknote — agent notes

Read this before changing code. User docs: [README.md](README.md).

## Commands

```bash
pnpm install
pnpm verify        # format → lint → typecheck → test → build → pack
pnpm typecheck
pnpm test
pnpm build
```

## Layout

- `src/host/` — Host half: services, tools, routes. No browser APIs.
- `src/client/` — browser half: React 19 components (TSX), slots, styles. No Node APIs.
- `src/shared/` — constants both halves import (`NAME`, `NS`, `PLUGIN_ID`).
- `lib/` — generated. Never edit by hand.
- `tests/` — one suite per half.

## Invariants

- `package.json` `name` === `src/shared/constants.ts` `NAME` === the client bundle id.
- The `window.__ModuleLoader__.load` wrapper is generated by `tsdown.config.ts`; source must not contain it.
- No network calls, no telemetry, no `console.log` in shipped code.
- Any destructive action must be reversible and must state its consequence.
