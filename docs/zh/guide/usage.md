# 使用

## 从输入框

点击工具栏的 **随手记**，卡片会带上当前草稿。

- **保存笔记**：保存文本，草稿保持不变。
- **保存并清空输入框**：Host 确认保存成功后，才清空输入框。输入框上方会出现回执，可以打开列表，或撤销并恢复草稿。
- **查看全部**：卡片右上角直接打开笔记页，括号里是已保存的笔记数；卡片里还没保存的文字会保留到下次打开。

不保存直接关闭卡片，不会改动任何内容。

## 从侧栏

**随手记** 页面按时间倒序列出笔记。用 **全部 / 未完成 / 已完成** 和搜索框筛选。标题上方的 **返回对话** 会回到你原来
的会话并显示会话名；点左侧栏的会话行效果相同。

## 标签

在笔记任意位置写 `#标签`，例如 `#工作`、`#release-1`。页面会在列表上方汇总所有标签；点击标签只看匹配的笔记，
再点一次（或点 **全部标签**）取消筛选。标签可以和完成筛选、搜索框叠加使用。导出的 Markdown 会原样保留标签。

## 行操作

每一行显示时间、捕获来源（从输入框保存时）和标签，可以复制、插入当前会话的草稿（即使本页正盖住对话）、
标记完成/重新打开或删除。
删除后会出现撤销提示，在提示关闭前点 **撤销** 可以原样恢复；连续删除多条时，提示里会出现 **全部撤销**，
一次恢复这一批笔记。**复制全部** 会把当前可见的笔记导出为 Markdown；
`primary+alt+S` 可打开捕获卡片。数据保存在本机 DSH home 下；窗口变窄时操作按钮会排在正文下方，不会挤压标签文字。

## 从 Agent

直接让模型“记一条笔记”。插件提供四个工具：

- `quicknote_add`
- `quicknote_list`
- `quicknote_done`
- `quicknote_delete`
