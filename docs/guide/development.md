# Development

```bash
pnpm install
pnpm verify
```

`pnpm verify` runs formatting, lint, type checking, both test suites, the build, the manifest check and
`npm pack --dry-run`.

To test the working copy inside DSH:

```bash
pnpm build
dsh plugin --profile <profile> add link:$PWD
```

Then restart DSH. The client bundle is generated by `tsdown.config.ts`; never edit `lib/` by hand.
